# Веб-ларёк — интернет-магазин для веб-разработчиков 🛒

> Интернет-магазин с корзиной, оформлением заказов и модальными окнами.  
> Проект демонстрирует навыки работы с TypeScript, ООП-архитектурой и событийной моделью.

## Стек технологий

- **Языки:** TypeScript, HTML5, SCSS
- **Сборка:** Webpack
- **Архитектура:** MVP (Model-View-Presenter) с брокером событий
- **Стилизация:** SCSS-модули

## Функциональность

✅ **Каталог товаров** — просмотр всех доступных товаров  
✅ **Карточка товара** — детальная информация в модальном окне  
✅ **Корзина** — добавление/удаление товаров, подсчет суммы  
✅ **Оформление заказа** — двухшаговая форма с валидацией  
✅ **Событийная модель** — все компоненты общаются через EventEmitter  
✅ **Адаптивный дизайн** — корректное отображение на всех устройствах
